# Widget Newtab

Chrome の新しいタブを、自由に並べ替え・リサイズできるウィジェットのダッシュボードに置き換える拡張機能です。時計、天気、ToDo、リマインダー、メモ、タイマー、写真、SwitchBot などのウィジェットがあります。

## 入れ方

1. このリポジトリを手元に置きます。次のどちらかで入れてください。
   - git を使う: `git clone https://github.com/hatopoppoppo/widget-newtab.git`
   - git を使わない: 右上の「Code」→「Download ZIP」でダウンロードし、好きな場所に解凍する
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、解凍したフォルダを選びます。
4. 新しいタブを開きます。「この拡張機能によって新しいタブが変更されました」と出たら「変更を保持」を選んでください。

右上の鉛筆のボタンで編集モードになり、ウィジェットの追加・移動・大きさの変更、全体設定ができます。

## 更新のしかた

新しいバージョンが出ると、新しいタブの右上に「新しいバージョン」のボタンが出ます。

### ボタン1つで更新する(Windows)

最初に1回だけ、拡張機能のフォルダの `native\install.bat` をダブルクリックしてください。これで、「新しいバージョン」のボタンから出る「今すぐ更新」を押すだけで、ファイルの入れ替えから再読み込みまで済みます。

- 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。
- 管理者権限は要りません。
- 拡張機能のフォルダを別の場所に移したときは、もう一度 `install.bat` を実行してください。
- 更新すると、拡張機能のフォルダは配布している中身と同じになります。フォルダに自分で足したファイルは消えます。
- やめるときは `native\uninstall.bat` を実行します。

### 手動で更新する

1. フォルダの中身を新しくします。
   - git で入れた場合: そのフォルダで `git pull`
   - ZIP で入れた場合: 新しい ZIP をダウンロードして解凍し、中身を前のフォルダに上書きする
2. 「新しいバージョン」のボタンから出る「再読み込み」を押します(全体設定の一番下からも押せます)。

設定とデータはそのまま残ります。

## 不具合の報告

全体設定の一番下にある「不具合を報告する」から送ってください。

## データの保存先

レイアウト・設定・ToDo などは Chrome の同期(`chrome.storage.sync`)に保存するので、同じ Google アカウントでログインしている PC 同士で共有されます。メモ、写真、背景の画像、SwitchBot のトークンはその PC だけに保存します。全体設定の「書き出し」でバックアップを取れます。
